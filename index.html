P—01 2026 Solo · open source

Chat Exporter for Claude

Your Claude chats, as files you own.

  • Source
  • Firefox add-on

A Firefox extension and a terminal program that export claude.ai chats to your disk. You browse your chats in the terminal, select a few and press Enter, and each one becomes a folder: the conversation in Markdown, every file Claude made in its final version, and the raw data to rebuild it later. It started as a console script I used for my own notes.

The login stays in the browser and the program does the real work, so your session never leaves Firefox. After the first release, a review showed the extension trusted whatever answered on its local port: another program on the same computer could have posed as mine and read every chat. I fixed it before shipping anything else, with a mutual HMAC handshake on the pairing token, and said so in the release notes.

P—02 2026 Solo · exam project

MovieApp

A movie and TV browser built on the TMDB API.

  • Live demo
  • Source

MovieApp shows trending and popular movies and series, and opens a detail page for each title with cast, director or creators, runtime and rating. It was my final exam for the Frontend JS module at ITS Tech Talent Factory. The brief set the features; the design and the code are mine.

It's plain JavaScript with no framework. Halfway through, the code had become hard to work on: the same logic lived in several files and I often didn't know where to make a change. So I stopped and refactored, moving shared code into a utils module and giving each file one job. It was the first time I really understood why code needs structure, and it turned out to be what made Angular click for me when I started using it.

  • HTML
  • CSS
  • TMDB API
